04 · Dell / Serviceability

Telemetry: scheduling, data format, and retries

Schedule

Frequencies live in a Helm ConfigMap. Different data types can use different intervals; cron jobs trigger the corresponding scripts.

Data

Hardware information and status, performance status, and events.

Data format

Collection scripts produce data in a format accepted by Dell’s backend.

Retry and packaging

Failures use exponential backoff through the next cycle; persistently failed items are excluded from the final archive.

The Helm ConfigMap lets each telemetry type use its own collection interval; collection scripts emit records in the format accepted by the Dell backend.

Bundle pipeline

NIM tool

Maintain the NIM tool and add features to support installation and related operations.

Firmware upgrade flow

Read the node’s current hardware inventory and use the catalog in the hardware bundle as the target firmware reference.

Version decision and execution

Use Dell System Upgrade CLI to compare versions. If an upgrade is needed, use Redfish to notify iDRAC to perform it.
